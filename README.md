# 제주, 천천히 한 바퀴

2028년 칠순 기념 제주 3개월 여행을 계획하는 웹앱입니다. 월별 여정, 올레길 27개 코스, 숙소 확인 사항, 주간 일정과 음식 정보를 보고 여행 예산을 계산할 수 있습니다.

## 사용 방법

1. `index.html`을 더블 클릭해 브라우저로 엽니다.
2. 다녀온 올레 코스를 체크하면 진행률이 표시됩니다.
3. 숙소·교통·식비와 기타 비용을 입력하면 3개월 예상 예산이 계산됩니다.

올레 완주 기록은 사용하는 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 지우면 기록도 사라지며, 다른 기기나 브라우저에는 공유되지 않습니다. 저장을 차단한 브라우저에서는 기록이 유지되지 않을 수 있습니다. 숙소 확인 체크와 예산 입력은 저장되지 않습니다. 지도와 외부 안내 링크는 인터넷 연결이 필요합니다.

## 파일 구성

- `index.html`: 화면, 디자인, 기능이 모두 들어 있는 웹앱
- `.nojekyll`: GitHub Pages에서 파일을 그대로 제공하도록 하는 빈 파일
- `.gitignore`: 공개 저장소에 넣지 않을 파일 목록
- `README.md`: 이 설명서

## GitHub Pages에 올리기

이 폴더의 파일을 저장소 맨 위에 올려 사용합니다. 별도 설치나 빌드, 서버 없이 작동하는 정적 웹사이트입니다. 사이트 내부 파일에 대한 루트 절대 경로는 없으며, 외부 지도와 관광정보 링크는 원래의 HTTPS 주소를 사용합니다.

공개 전에 개인정보가 들어 있는 파일을 추가하지 않았는지 다시 확인하세요. 여행 장소와 운영 정보는 출발 전에 공식 안내에서 확인하세요.

## 맛집 정보

음식 소개 아래에 트립어드바이저 제주도 음식점 목록의 추천 순서 상위 5곳을 표시합니다. 식당별 평점, 리뷰 수, 음식 안내, 지도 및 리뷰 링크를 제공합니다. 2026년 10월 20일 확인한 자료이며 자동 갱신되지 않습니다. 추천 순서는 평점 외에 조회·위치 등도 반영합니다.
